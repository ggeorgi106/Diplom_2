# Дипломный проект. Задание 2: API-тесты

Автоматизированные тесты API для сервиса Stellar Burgers.

## Что протестировано

### Создание пользователя
- Создание уникального пользователя.
- Ошибка при создании уже существующего пользователя.
- Ошибка при создании пользователя без обязательного поля.

### Авторизация пользователя
- Авторизация существующего пользователя.
- Ошибка авторизации с неверным логином и паролем.

### Изменение данных пользователя
- Изменение email авторизованного пользователя.
- Изменение имени авторизованного пользователя.
- Ошибка изменения данных без авторизации.

### Создание заказа
- Создание заказа авторизованным пользователем.
- Создание заказа без авторизации.
- Ошибка создания заказа без ингредиентов.
- Ошибка создания заказа с неверным хешем ингредиента.

### Получение заказов пользователя
- Получение заказов авторизованного пользователя.
- Ошибка получения заказов без авторизации.

## Структура проекта

- `api/` — методы для работы с API.
- `tests/` — автотесты.
- `helpers.py` — вспомогательные функции.
- `urls.py` — URL и эндпоинты API.
- `requirements.txt` — зависимости проекта.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest tests -v
```

## Запуск тестов с Allure

```bash
pytest tests -v --alluredir=allure_results
```

## Просмотр Allure-отчёта

```bash
allure serve allure_results
```
